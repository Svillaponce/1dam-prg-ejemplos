# 1dam-prg-ejemplos

Repositorio con ejemplos de programación realizados en clase.

## Estructura

```text
programacion-1dam-ejemplos/
│
├── README.md
│
├── tema-01-fundamentos/
│   ├── pom.xml
│   ├── 01-variables/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   ├── 02-condicionales/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   └── 03-bucles/
│       ├── pom.xml
│       └── src/main/java/Main.java
│
├── tema-02-poo/
│   ├── pom.xml
│   ├── 01-clases-objetos/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   ├── 02-encapsulacion/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   └── 03-herencia/
│       ├── pom.xml
│       └── src/main/java/Main.java
│
├── tema-03-colecciones/
│   ├── pom.xml
│   ├── 01-arraylist/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   ├── 02-hashmap/
│   │   ├── pom.xml
│   │   └── src/main/java/Main.java
│   └── 03-hashset/
│       ├── pom.xml
│       └── src/main/java/Main.java
│
└── tema-04-streams/
    ├── pom.xml
    ├── 01-filter/
    │   ├── pom.xml
    │   └── src/main/java/Main.java
    ├── 02-map/
    │   ├── pom.xml
    │   └── src/main/java/Main.java
    ├── 03-sorted/
    │   ├── pom.xml
    │   └── src/main/java/Main.java
    └── 04-reduce/
        ├── pom.xml
        └── src/main/java/Main.java
```

Cada carpeta dentro de cada tema tiene su propia estructura `src/` con un `Main.java` inicial.
Cada tema incluye su `pom.xml` de Maven para gestionar sus subcarpetas como módulos.
